# Scheduled Downloader

## ساخت APK با گوشی و GitHub Actions
1. در مرورگر گوشی وارد GitHub شوید و از منوی `New repository` یک مخزن بسازید.
2. همه محتویات استخراج‌شده این پروژه را داخل ریشه مخزن آپلود کنید؛ خود پوشه `ScheduledDownloader` را به‌عنوان یک پوشهٔ تو در تو آپلود نکنید. فایل‌هایی مثل `settings.gradle.kts` و پوشه `.github` باید مستقیماً در ریشه باشند.
3. در تب Actions، در صورت نمایش پیام، اجازه اجرای workflowها را فعال کنید.
4. پس از پایان اجرای `Build APK`، از صفحه اجرای workflow بخش Artifacts، فایل `ScheduledDownloader-APK` را دریافت کنید.
5. APK را نصب کنید. اگر لازم بود در تنظیمات گوشی اجازهٔ نصب از منابع ناشناس را برای مرورگر یا فایل‌مدیر بدهید.

## استفاده
برنامه را باز کنید، URL مستقیم فایل (نه صفحهٔ وب) و در صورت نیاز نام فایل را وارد کنید، سپس تاریخ و ساعت محلی را انتخاب و ذخیره کنید. برای زمان‌بندی دقیق، اجازهٔ `Alarms & reminders` را در صفحه‌ای که برنامه باز می‌کند فعال کنید. در اندروید ۱۳ یا جدیدتر اجازهٔ اعلان‌ها را بدهید. برای اجرای قابل‌اعتماد، برنامه را از محدودیت بهینه‌سازی باتری خارج کنید.

فایل‌ها در اندروید ۱۰ و بالاتر در `Downloads/ScheduledDownloads` ذخیره می‌شوند. لینک باید مستقیم و قابل دسترسی بدون ورود باشد. دانلودهای ناموفق در فهرست با پیام خطا نمایش داده می‌شوند.
